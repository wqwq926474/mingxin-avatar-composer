# 明心商学 · 头像合成器

一个手机端网页：上传头像后，自动抠出人像，并合成到“金秋盛棠 / 礼遇相蓬”活动海报模板中。

## 使用说明

1. 用手机浏览器打开 `index.html`。
2. 点击“从相册选择”或“拍照上传”。
3. 等待 AI 抠图和合成完成。首次使用需要联网下载一次模型文件，之后会由浏览器缓存。
4. 合成后可用“大小 / 左右 / 上下”滑杆微调人物位置。
5. 点击“下载合成海报”保存成品。

照片只在你的浏览器本地处理，不会上传到其他服务器；只有 AI 抠图代码和模型文件会从公开 CDN 加载。

## 文件说明

- `index.html`：成品网页，模板图片已内嵌，可单独打开或部署。
- `template.jpg`：原始模板图片，保留备用。
- `source.html`：可读源码，模板图片以占位符形式保存，便于后续修改。
- `README.md`：本说明。

## 部署成手机网址

这个文件夹可以直接部署到 GitHub Pages、Netlify、Vercel 或任意静态网站托管服务。部署时文件夹里的 `index.html` 是唯一必需文件。

当前线上地址：

<https://wqwq926474.github.io/mingxin-avatar-composer/>

如果在大陆网络环境下无法打开 GitHub Pages，可能需要更换托管平台或使用可访问的 CDN 加速。

如果只在电脑本地预览，建议用静态服务器打开，例如在当前文件夹执行：

```powershell
python -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000/index.html`。

## 注意事项

- AI 抠图对人物背部与复杂背景的识别会有个体差异，头发边缘偶尔需要人工调整。
- 手机首次加载模型时流量较大，建议在 Wi-Fi 环境测试。
- 当前模板、品牌名称和宣传语均来自你提供的模板图片，使用时请确认素材授权。
